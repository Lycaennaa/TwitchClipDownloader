Download folder access

Downloads stream directly into creator folders under the selected Twitch Clips folder.

1. Select root folder

Select the folder containing creator subdirectories. The directory handle is stored in extension IndexedDB. If using Brave > new tab > brave://flags > type "file-system-access-api" then click default then change to enable then relaunch browser.

2. Test streaming

Optional diagnostic: write a temporary file into an existing creator directory, then remove it. Use a current Twitch media URL from the dashboard.
